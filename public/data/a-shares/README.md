全部上市时刻为 09:30 开盘代理，非逐股确认首笔。15 只股票上市日与首个行情日不同，已从二者较晚日期观察行情。全市场借壳/并购身份重置尚未逐股核实；当前上市股票池存在存活者与前视选择偏差。历史改进主用神为样本内拟合，不能解释为样本外预测能力。

`validation.json` 独立检查所有公式、样本、筛选门槛及汇总；`model_equivalence.json` 检查与美股冻结计算的一致性；`forecast_files.json` 检查年度下载文件与逐股结果的一致性。
